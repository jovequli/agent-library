# Project notes

Agent Library is an independent local archive reader, not affiliated with or
endorsed by Anthropic, OpenAI or another model provider. Provider names identify
compatible sources and handoff destinations; they do not imply authorization.
The project uses its own name and mark, without provider logos or client software.

- Users choose local files they are authorized to import and decide whether to
  share a handoff. The application does not automatically submit archives to a
  model provider.
- The source-code license does not grant rights to imported conversations,
  images or other materials. Bundled software retains its third-party licenses.
- Source releases contain code, documentation and fictional examples, never
  personal libraries, credentials or private backups.
- Maintained features cover local reading, search, handoff files and backups;
  they do not include provider-account sign-in, credential reuse, unauthorized
  scraping, access-control bypass or model training. New online integrations
  need their applicable terms checked separately.

These are project scope statements, not extra conditions added to the source
license or a guarantee covering every use of an archive.
