# Changelog

## 0.1.0 — public preview (2026-11-16)

- Provider-neutral, independent conversation libraries with a bilingual offline reader.
- Claude export, Claude Code, Cowork, and portable context-pack import adapters.
- Source-backed search, Markdown, mathematics, local images and message previews.
- Editable task handoffs, full transcript and requirements export, context-pack reimport.
- Additive native-ID imports with immutable, validated generations and stale-snapshot preservation.
- Versioned, checksummed private backups and restore into a new independent library.
- Lossless migration from the earlier normalized archive, including all record
  types, duplicate historical UUIDs, exact image bindings, separate task galleries
  and original transcript/requirements/handoff evidence.
- Synthetic examples, regression tests, source release boundaries and packaging checks.

The first public preview includes Chinese and English documentation with
fictional demonstration screenshots. Local verification and platform coverage
are recorded in the project documentation and GitHub Actions checks.
